# Демо-бот барбершопа «Чёрный дуб»

Витринный бот для показа клиентам в двух версиях: **Telegram** (`bot.py`, aiogram 3) и **MAX** (`max_bot.py`, maxapi). Логика, цены и данные общие. Инструкция для MAX ниже, в разделе «Запуск в MAX». Заведение и барберы выдуманные.
Всё, что нужно поменять под реального клиента, лежит в `config.py`.

## Что умеет бот

**Для гостя**
- Запись за 4 шага: услуга → барбер (или «любой свободный») → день → время → подтверждение
- Расписание с учётом длительности услуги, выходных барберов, часов работы (в воскресенье короче), запрета двойной записи и «не позднее чем за час»
- Цены: у каждого барбера свой коэффициент, утренняя скидка 10% (пн-пт до 12:00)
- Карточки барберов: опыт, специализация, рейтинг, цены, отзывы, запись «к этому мастеру»
- Каталог из 9 услуг с описанием, длительностью и ценой по каждому барберу
- Отзывы и рейтинги: оценка 1-5 + комментарий после визита
- Мои записи: список, отмена (не позднее чем за 2 часа), история визитов, файл `.ics` для календаря
- Напоминания за сутки и за 2 часа до визита
- Акции, адрес с геолокацией и кнопками «Яндекс Карты» / «2ГИС», FAQ, связь с администратором

**Для администратора** (команда `/admin`)
- Расписание на сегодня/завтра и далее, кнопки «визит состоялся», «не пришёл», «отменить»
- Статистика за 30 дней: визиты, выручка, средний чек, отмены, неявки, топ услуг, рейтинг
- Рассылка всем клиентам с предпросмотром
- Уведомления о новых записях, отменах, низких оценках, сообщениях клиентов; ответ клиенту прямо из бота
- Кнопка «Заполнить демо-данными» для показа админки не пустой

## Запуск

```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN и ADMIN_IDS
python bot.py
```

1. Создайте бота у [@BotFather](https://t.me/BotFather), токен впишите в `.env`.
2. Напишите боту `/id`, свой ID впишите в `ADMIN_IDS`, перезапустите бота.
3. Откройте `/admin` → «Заполнить демо-данными».

**Важно про Telegram в РФ.** На сервере в России Telegram API может не открываться. Берите сервер за границей
или укажите прокси в `PROXY` (для socks нужен `aiohttp-socks`, он есть в requirements).

## Как показывать клиенту

1. `/start` → «Барберы» → карточка мастера → «Записаться к …»
2. Пройти запись до конца, показать утреннюю скидку 🌅 и сообщение о подтверждении
3. Со второго телефона (или аккаунта) открыть `/admin` → «Сегодня»/«Завтра» → увидеть новую запись → «✅ визит состоялся»
4. На телефоне гостя: пришёл запрос на оценку → поставить звёзды → отзыв появился в «Отзывы»
5. Показать «Акции», FAQ, «Адрес и контакты»

## Адаптация под клиента

Меняйте только `config.py`: название и адрес (`SHOP`), барберов (`BARBERS`), услуги и цены (`SERVICES`),
график (`HOURS_*`), утреннюю скидку, акции (`PROMOS`), вопросы (`FAQ`).
Демо-отзывы для рейтингов лежат в `SEED_REVIEWS` в `storage.py`, удалите их перед боевым запуском.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-версия: хендлеры aiogram, меню, админ-панель, напоминания |
| `max_bot.py` | MAX-версия: те же функции на библиотеке maxapi |
| `storage.py` | SQLite и вся логика: слоты, цены, отмены, отзывы, статистика |
| `config.py` | Данные заведения и настройки |
| `test_logic.py` | 21 тест логики: `python -m unittest -v` |

## Ограничения демо

- Хранение в SQLite, FSM-состояния в памяти: после перезапуска незавершённая запись начинается заново
- Оплата онлайн не подключена: оплата в салоне
- Один филиал, без индивидуальных графиков и перерывов у барберов
- Напоминания работают, пока запущен процесс бота

# Запуск в MAX

## 1. Регистрация бота в MAX (до написания кода)

1. Откройте [business.max.ru/self](https://business.max.ru/self), войдите по номеру телефона и пройдите **верификацию профиля** (через Госуслуги или банк).
2. Раздел «Чат-боты» → «Создать»: имя, описание, аватар.
3. Дождитесь **модерации** (по описаниям платформы это до пары рабочих дней). Пока бот не прошёл модерацию, токена нет.
4. Токен: откройте бота → «⋮» → «Настройки» → значок копирования у поля с токеном. Никому его не показывайте.

**Кто может создать бота.** Источники расходятся. Справка MAX: нужен верифицированный профиль организации, ИП или самозанятого (ИП и юрлицо до 5 ботов, самозанятый до 2). Статьи на Habr и Timeweb пишут, что только юрлица. Проверьте на business.max.ru, пройдёт ли ваш профиль верификацию, до того как обещать клиентам бота в MAX.

## 2. Установка и запуск

```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install maxapi python-dotenv
cp .env.example .env
```

В `.env` заполните:

```
MAX_BOT_TOKEN=токен_из_кабинета
MAX_ADMIN_IDS=            # заполните на шаге 3
```

Запуск: `python max_bot.py`. Бот работает через long polling, при старте сам снимает webhook-подписку.

## 3. Админ-доступ

1. Откройте своего бота в MAX и нажмите «Начать».
2. Напишите ему `/id`: он ответит вашим ID в MAX (это не Telegram-ID).
3. Впишите ID в `MAX_ADMIN_IDS` в `.env` и перезапустите бота.
4. Напишите `/admin` или нажмите «Админ-панель» в меню, затем «Заполнить демо-данными».

## 4. Постоянная работа на сервере

MAX работает в РФ без VPN, поэтому подойдёт обычный российский VPS (Timeweb, Beget, Amvera и т. д.) без прокси.

```bash
# на сервере, из папки с ботом
nohup venv/bin/python max_bot.py > bot.log 2>&1 &     # быстрый вариант
```

Надёжнее запускать как systemd-сервис, чтобы бот стартовал после перезагрузки и перезапускался при падении. Файл `/etc/systemd/system/barbershop-max.service`:

```
[Unit]
Description=Barbershop MAX bot
After=network.target

[Service]
WorkingDirectory=/opt/barbershop_bot
ExecStart=/opt/barbershop_bot/venv/bin/python max_bot.py
Restart=always
User=bot

[Install]
WantedBy=multi-user.target
```

Затем: `sudo systemctl enable --now barbershop-max` и логи `journalctl -u barbershop-max -f`.

## 5. Чем MAX-версия отличается от Telegram

- Нет постоянной клавиатуры внизу чата: главное меню это inline-кнопки, на каждом экране есть «🏠 Меню».
- Номер телефона запрашивается кнопкой «Отправить мой номер» (или можно написать текстом).
- Админ-панель открывается и командой `/admin`, и кнопкой в меню (видна только админам).
- База отдельная (`MAX_DB_PATH`), записи в Telegram и MAX не пересекаются.
- Документация maxapi предупреждает, что long polling не рекомендуется для боевого режима. Для демо и небольших заведений этого достаточно; для крупного проекта переходите на webhook (нужен HTTPS).

## 6. Что проверено, а что нет

Логика бота прогнана на заглушке библиотеки: запись от начала до подтверждения, контакт из vCard, отмена, отзывы, админка, рассылка, напоминания, устаревшие сессии (около 40 проверок). **С настоящим MAX и реальной библиотекой maxapi бот не запускался.** Если при первом запуске появится ошибка импорта или API, пришлите текст ошибки: скорее всего, это мелкое различие версий библиотеки. Если у вас не работает загрузка `.ics`, это не критично: бот сообщит об этом, запись сохранится.
